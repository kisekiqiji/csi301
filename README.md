# 西浦空间 · CampusSpace

CSI301 Mobile Computing 小组项目 —— 一个面向西浦（SIP 校区）的校内空间资源查询 App。

学生常见的三个痛点：**找自习室难、预约信息分散、找公共设备麻烦**。这个 App 把分散的信息聚到一处，
用「当前状态」帮你决定现在去哪，再用「空间纸条」把线下实体和人的经验连起来。

## 功能

底部四个 Tab，并提供楼栋选择、空间详情、纸条发布和本机账号登录页面：

| 页面 | 功能 |
|---|---|
| 1 首页 / 教学楼 | 指定日期和时间查询空教室，支持跨楼栋搜索、容量/设施筛选，以及明显的楼栋选择入口 |
| 2 教室详情 | 设施标签、昨天~后天日期切换、**自定义 View 时间轴色带**（灰=空闲 蓝=有课 红线=现在）、本教室纸条 |
| 3 可预约空间 | 讨论室 / 静音仓 / 讨论区 / 图书馆座位 四类分类 + 区域联动筛选；顶部「现在可去」按当前时间推荐 3 个立即可用资源 |
| 4 可预约详情 | 讨论室与静音仓按时段列表展示；图书馆按数据库坐标生成座位网格，保留官方状态与未知状态 |
| 5 公共设备 | 楼栋 + 楼层双下拉，饮水机 / 打印机 / 公共休息处 / 开放座位区 分类，设备报修纸条 |
| 6 纸条发布 | 失物招领 / 空间碎碎念 / 设备报修 三类，可配图，位置强制绑定当前空间 |
| 楼栋选择 | 按校区展示教室与公共空间的大卡片，显示楼栋名称和已有资源数量 |
| 我的 | 查看本机账号资料、编辑昵称、查看本人纸条和数量、**我的收藏**、**演示控制台**、使用规则及退出登录 |
| 收藏空间 | 首页列表、教室详情和预约详情均可点星收藏；收藏只存本机，状态实时计算 |
| 演示控制台 | 拨表切换虚拟时间、快速场景、恢复真实时间、重建演示快照；进程重启后演示时间仍保留 |
| 登录 / 注册 | 本地账号、加盐密码哈希、失败冷却；游客可查询空间，发布纸条需登录 |

**预约一律跳转学校官方系统**，本 App 只做信息聚合与状态展示，不内置预约交易。

## 演示模式（答辩用）

入口有两个：点击首页顶部数据条，或在「我的」页点「演示控制台」。

- **快速场景**：上课中 10:30 / 午休 12:30 / 下午课 14:30 / 晚自习 19:30 / 明天上午 / 周六下午。
- 选择场景后会同时做两件事：把 `TimeProvider` 的「现在」拨到目标时间，并重建演示课表、预约时段和座位快照。只改时钟会让旧快照失效，所以两者必须一起变。
- 演示时间保存在本机，杀掉进程重开仍然有效；「恢复真实时间」会清掉演示时钟并按真实时间重建。
- 重建只替换 `DEMO_TIMETABLE` / `DEMO_BOOKING` 快照和 `SEED-AUTHOR-*` 演示纸条；本机账号、用户自己发布的纸条和收藏不受影响。
- 演示状态只影响本机显示与本地数据，不访问网络，也不新增任何权限。

## 技术栈

- Java + XML 布局（Empty Views Activity，minSdk 24 / targetSdk 37）
- 底部导航 `BottomNavigationView` + 4 个 Fragment
- `RecyclerView` 展示空间、预约与纸条列表
- **Room** 本地数据库（15 张表，版本 3）+ 演示模板初始化，支持旧版本无损迁移
- 自定义 `View`（`TimelineView`）绘制时间轴色带
- `TimeProvider` 可拨表的时钟抽象 + `DemoClock` 本机持久化，用于答辩演示
- `SharedPreferences` 保存本机收藏与演示时钟，不升级数据库结构
- 隐式 `Intent` + `ACTION_VIEW` 跳转官方预约系统
- Photo Picker 选图（无需相册权限），图片复制到应用私有目录

App **不声明任何权限**：不用 INTERNET（跳浏览器）、不用存储权限（Photo Picker）、不定位，飞行模式也能运行。

本机账号不对接学校统一认证，账号与纸条保存在应用私有目录；密码不以明文保存。系统备份已关闭，清除应用数据或卸载后无法找回本机账号。使用与安全边界见 [本机账号说明](docs/local-accounts.md)。

## 构建

```bash
# 需要 Android Studio（自带 JDK）与 Android SDK
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` 里有本机 SDK 路径，不纳入版本控制，由 Android Studio 自动生成。

## 数据说明

`app/src/main/assets/seed.json` 为**模拟数据模板**（3 栋楼 × 5 层 × 15 间教室 = 225 间、1815 条周课表、
10 个讨论室、26 个静音仓、720 个预约时段、100 个图书馆座位、70 个公共设施点位（40 个设备、30 个公共空间）、50 条纸条）。
原始数据受课程豁免，线上版本将对接教务系统导出。

模板会转换为具体日期课次和预约状态批次。教室状态由有效课表批次与当前时间计算；缺失或过期数据显示未知。座位演示状态只覆盖今天。

`assets/catalog.json` 提供需求中的楼栋目录和图书馆，尚无资料的楼栋保留空列表。楼层、空间、预约分组与网格位置均从数据库读取。官网首页占位地址已清空，实际预约链接待配置。

数据库字段、完整 ER 图、批次导入及页面对应关系见 [数据库说明](docs/database.md)。Room 导出的版本结构位于 `app/schemas/`。
